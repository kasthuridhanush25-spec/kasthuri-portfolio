# Kasthuri Dhanush — Personal Portfolio

A responsive personal portfolio built with **HTML5 and CSS3 only**, matching the Week 1 internship requirement.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colours, typography and mobile navigation

## Run locally
1. Extract this ZIP file.
2. Open the `kasthuri-portfolio` folder.
3. Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `kasthuri-portfolio`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Copy the website URL shown in the Pages section.

## Submit to the internship portal
Submit both:
- GitHub repository URL
- Published GitHub Pages live URL

## Before submitting
- Check the email address and personal details in `index.html`.
- Preview on both desktop and mobile.
- Replace or add project links only when you have real project URLs.
- The portfolio is a static site; it does not use JavaScript or a backend.
